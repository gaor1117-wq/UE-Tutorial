## 本课核心逻辑

1. UE 的底层逻辑是**游戏关卡**：打开工程 = 打开一张地图（Map），一切编辑都在地图里进行。  
2. 拿到渲染组的工程文件：**先整理、后动手**——建自己的文件夹、复制所需资产、分类大纲，绝不改原始文件。  
3. 灯光三步法：**氛围光定调 → 定向光打主光 → 矩形光补暗部**；过曝就用“光照通道”局部隔离。  

了解即可（现阶段用不到）：VRED 流程只需知道原理——分色方案要提前跟渲染组对齐，要求对方在 VRED 里做好“合并几何体”，保证每种分色逻辑在 UE 里都能单独编辑。

# 第一课知识点（按能力点组织）

## A 界面与视窗

**干什么用：**熟悉窗口布局，视角怎么动，是所有操作的基础。

**怎么做：**
1. 核心四块：**主视窗 / 大纲 / 细节 / 内容浏览器**；窗口消失可从顶部菜单重新调出。  
2. 窗口可拖拽、可开多个；推荐双屏，把“细节”和“材质编辑器”放副屏。  
3. 多视窗：一个固定视角观察，另一个调参数实时看效果（**不动它就是锁定**）。  
4. Ctrl + 1 / 2 / 3 / 4 存视角书签，镜头跑丢一键切回。  

**注意：**
- 显示模式常规用**光照**；**路径追踪**只是讲师当前急项目（文件未完善）的美化手段，不要照搬。  
- 摄像机速度调小一点，方便精调细节。  

> 【📷 截图位】界面四块窗口布局 / 双屏摆放 / 顶部菜单调出窗口  
> 【🎞 动图位】多视窗对照调参数（一个视角不动=锁定）

## B 工程文件初始化（拿到文件第一步）

**干什么用：**隔离个人修改，不污染渲染原始文件，方便版本对比。

**怎么做：**
1. 和渲染组确认：主渲染 Map 名称；如果是多关卡拆分文件，要求对方整合交付。  
2. 新建个人文件夹：命名 = 日期 + 项目代号（例：`26.9-9 G01A`），内部再建**地图 / 关卡序列 / 材质**三个子文件夹。  
3. 复制资产：主 Map、关卡序列、公共材质用 Ctrl + C 粘贴到自己文件夹内，后续只编辑副本。  
4. 大纲分类：把散乱的模型、灯光资产（Shift 多选）分别拖进“模型 / 光”文件夹。  

**注意：**
- 命名**禁止中文和特殊标点**，否则 UE 无法识别。  
- 检查资产：用大纲里的小眼睛开关对比；看不到的物体按 F 定位。  
- 光拖不动：点选后在细节面板调“移动性”。  

> 【📷 截图位】个人文件夹结构（地图/关卡序列/材质）  
> 【📷 截图位】大纲分类前后对比  
> 【🎞 动图位】复制资产到个人文件夹 + 大纲拖拽分类演示

## C 三大资产（内容浏览器）

- **地图（Map）**：当前打开的关卡；内容浏览器与工程文件的 `Content` 文件夹一一对应——资产丢了直接去本地文件夹查。  
- **关卡序列**：UE 4.5+ 版本绑定固定摄像机；渲染组工程文件里的镜头都在里面。**想用固定摄像机，必须先打开对应关卡序列。**  
  - 新建：序列文件夹右键 → 过场动画 → 关卡序列 → 新建相机。  
- **材质**：分母球（公共，勿改）和材质实例（自建）；自定义材质必须从 `automotive materials` 材质包 Ctrl + C / Ctrl + V 复制出来再编辑。  

> 【📷 截图位】内容浏览器与 Content 文件夹对应关系 / 关卡序列新建相机入口

## D 材质替换

### 单个替换
1. 左键选部件（黄色高亮，大纲同步高亮）。  
2. 细节面板 → 材质 → 点搜索 / 文件夹图标 → 内容浏览器自动跳到对应材质球。  
3. 材质球 Ctrl + C → 个人文件夹 Ctrl + V → 双击进入材质编辑器修改。  

### 批量替换（同材质全部换）
1. 选中任一部件 → 菜单 **选择 → 材质 → 拥有相同材质**，快速选中所有同材质部件。  
2. 转一圈 + F 键检查是否选全。  
3. 选新材质球 → 点箭头符号附着替换。  

### 微调选择（少选）
- Ctrl + 左键取消部分色块（改配色逻辑时少选）。  

> 【📷 截图位】细节面板材质入口 / “拥有相同材质”批量选中效果  
> 【🎞 动图位】同材质批量替换 + Ctrl左键反选演示

## E 灯光搭建（本课重点）

### E1 氛围光：Ultra Dynamic Sky（UDS）
- 作用：控制整体氛围的天气系统（主氛围光，5.4 – 5.7 版本渲染组常用）。  
- 关键参数：Sun（日光亮度）／Base Control → Lighting Brightness（光照强度）／Time of Day（日光照射方向）。  
- 习惯：调弱一些，避免阴影太实，保留自然 HDR 氛围。  

> 【📷 截图位】UDS 参数面板（Sun / Lighting Brightness / Time of Day）

### E2 主光：定向光 Directional Light
- 作用：柔和、匀称的平行光（建议自己新建，别依赖 UDS 自带的）。  
- 新建：工具栏 → 光源 → 定向光源 → 拖入光文件夹。  
- 关键参数：圆角度拉大 → 柔和平行光（约 20/10 保留弱阴影，80–100 基本无形）；强度控制亮暗。  
- 方向：调旋转（不是位置！）；视口里光源图标有箭头显示入射方向。  

> 【📷 截图位】定向光“圆角度”对比  
> 【🎞 动图位】旋转定向光改变入射方向演示（强调：不是改位置）

### E3 补光：矩形光 Rect Light
- 作用：打亮门板等暗区；装饰件/方向盘/金属件可按需单独补。  
- 参数：强度/衰减半径/宽度/高度（长宽按车型调整）。  

> 【📷 截图位】矩形光位置示例  
> 【🎞 动图位】矩形光强度与衰减半径调节对比

### E4 光照通道（防过曝神器）
- 什么时候用：补光导致局部过曝时。  
- 怎么做：选目标部件 → 层级选所有后代 → 细节面板搜索通道（先取消母项选择）→ 让部件和补光光源都开通道1、关通道0。  
- 想让某部件完全不受光：把它所有通道都勾掉。  
- 注意：非必要不用，无通道隔离的全局光照更真实。  

> 【📷 截图位】光照通道设置（部件 + 补光灯同时设置）  
> 【🎞 动图位】过曝→开通道→过曝消失对比

### E5 后期盒子 Post Process Volume
- 作用：类似滤镜，不改真实光源，只调画面显示。  
- 默认保留渲染组参数即可；可微调：光晕强度、曝光、边缘暗角。  
- 调灯光时一直开着看效果。  

> 【📷 截图位】后期盒子参数（光晕/曝光/暗角）

# 避坑清单（第一课）

- 命名用了中文 / 特殊符号 → UE 拒绝保存。  
- 直接改公共材质母球 → 影响全工程。必须先复制。  
- 想改光的方向却去调位置 → 无效，要调旋转。  
- 显示模式用路径追踪 → 卡且非标准流程，常规用光照。  
- 补光导致整图过曝 → 用光照通道隔离，而不是一味调低光强。  
- “相同材质”选中后不检查 → 可能误选漏选，转一圈 + F 检查。
